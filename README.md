#директория page_object включает классы для всех тестируемых страниц
#в директории tests находятся файлы с тестами, причем каждому файлу соответствует отдельная страница
#в файлах директории locators заданы локаторы, применяемые в тестах
#в файле conftest.py описаны фикстуры, требуемые для выполнения тестов
#в файле data.py содержатся тестовые значения для заполнения полей ввода
#директория allure_results хранит JSON-файлы с итогами тестирования, предназначенные для формирования отчетов Allure
#в файле requirements.txt указаны все внешние библиотеки, необходимые для запуска тестов, что позволяет установить их одной командой
#файл README.md описывает структуру проекта и выступает в роли инструкции по использованию

#тесты в файле test_logo_redirect проверяют перенаправление на главную страницу сервиса и главную страницу «Дзена», которое осуществляется при нажатии на различные элементы логотипа в заголовке сайта
#тесты в файле test_main_page проверяют точность отображаемого текста в раскрываемых блоках раздела «Вопросы о важном» на главной странице приложения
#тесты в файле test_order_page охватывают полный цикл успешного оформления заказа. Через механизм параметризации передаются два различных набора пользовательских данных. Начало процесса оформления заказа инициируется из двух разных точек входа

#Allure-отчёт в виде веб-страницы создаётся с помощью команды allure serve allure_results
